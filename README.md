# ARVAELLE — Gold jewellery, Dubai

Static website for ARVAELLE (gold-plated jewellery, WhatsApp ordering, same-day Dubai delivery).

- `index.html` — the whole site (English + Arabic, product pages, category pages, policies, journal)
- `img/` — product photos
- Settings to edit are at the top of the `<script>` in `index.html` (`CONFIG` and `PRODUCTS`)

Deploy: import this repo in Vercel (framework preset: **Other**, no build command, output directory: root).
